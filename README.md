# 📊 Modern Data Warehouse & Analytics Project

A modern **Data Warehouse project** built using **SQL Server**, focusing on ETL, data modeling, and analytics.

## 🚀 Project Overview

This project demonstrates an end-to-end data warehouse workflow:

* Data extraction and ingestion
* ETL process
* Data cleaning and transformation
* Data warehouse design
* Dimensional data modeling
* Fact and dimension tables
* Data quality and validation
* Analytical SQL queries
* Business intelligence and reporting

## 🛠️ Technologies

* SQL Server
* T-SQL
* SQL Server Management Studio (SSMS)
* ETL
* Data Modeling
* Power BI
* Git & GitHub

## 🏗️ Architecture

The project follows a **Medallion Architecture**:

**Bronze → Silver → Gold → Analytics**

* **Bronze:** Raw source data
* **Silver:** Cleaned and transformed data
* **Gold:** Business-ready dimensional model
* **Analytics:** Reporting and business insights
